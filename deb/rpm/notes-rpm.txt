.TH 'ip-range' "1" "23 JUNE 2025" "ip-range version 0.10" "User Commands"
.TP
.SH NAME ip-range - utility, which calculating network settings usage IP-address and mask
.TP
.SH SYNOPSYS
.TP
.SH ip-range IP-address mask
.TP
.SH ip-range --help
.TP
.SH OPTION
.TP
\fB\--help\fR small help message.
.TP
.SH DESCRIPTION
.TP
        ip-range calculating:
 - the network range;
 - count IP-addresses in the network range;
 - IP-address default gateway;
 - minimum IP-address in the network;
 - maximum IP-address in the network;
 - IP-address for broadcasting.
.TP
Parameters, must specify: IP-address (not CIDR format) and mask (CIDR format). IP-address default gateway and broadcast are subtracted from the total number (count) of IP-addresses. In this case, the default gateway address in the specified network may differ (it should be noted that on some devices and firmware it is hard-coded as the first IP-address in the network). Shown count available IP-address to use. Networks /0, /31 and /32 not calculated (hardcode).
.TP
.SH EXAMPLE
 ip-range 192.168.1.0 24
 --------------------------------------------------------
 IP-address:                             [192.168.1.0]
 IP-mask:                                [24]
 Network:                                [192.168.1.0/24]
 Count IP-address:                       [254]
 IP-address default gateway:             [192.168.1.1]
 IP-address min:                         [192.168.1.2]
 IP-address max:                         [192.168.1.254]
 IP-address broadcast:                   [192.168.1.255]
 --------------------------------------------------------
